## 1. Hyperparameter Search Results (JSON Files)

**Files:** `hp_results_bert.json`, `hp_results_electra.json`, `hp_results_roberta.json`

### Structure

Each JSON file contains:

```json
{
  "best_model_info": {
    "params": {
      "dropout_rate": 0.1,
      "lr": 2e-5,
      "batch_size": 16,
      "weight_decay": 0.0
    },
    "val_accuracy": 0.936,
    "val_precision": 0.935,
    "val_recall": 0.934,
    "val_f1": 0.934,
    "val_auc_pr": 0.987,
    "model_path": "./hp_models/bert_...",
    "training_time_seconds": 1234.56,
    "model_size_mb": 440.23,
    "total_parameters": 110057474
  },
  "all_results": [
    {
      "params": {...},
      "val_accuracy": 0.936,
      "val_precision": 0.935,
      "val_recall": 0.934,
      "val_f1": 0.934,
      "val_auc_pr": 0.987,
      ...
    },
    ...
  ],
  "total_training_time_seconds": 19752.34,
  "num_models_trained": 16
}
```

### Key Fields

- **`best_model_info`**: Information about the best performing model (highest validation accuracy)
- **`all_results`**: List of all 16 hyperparameter combinations tested
- **`params`**: Hyperparameters used for this model
  - `dropout_rate`: Dropout probability (0.1 or 0.3)
  - `lr`: Learning rate (2e-5 or 3e-5)
  - `batch_size`: Training batch size (16 or 32)
  - `weight_decay`: L2 regularization (0.0 or 0.01)
- **`val_accuracy`**: Validation accuracy (0.0 to 1.0)
- **`val_precision`**: Macro-averaged precision
- **`val_recall`**: Macro-averaged recall
- **`val_f1`**: Macro-averaged F1 score
- **`val_auc_pr`**: Area Under the Precision-Recall Curve (macro-averaged)
- **`model_path`**: Path to saved model weights (.pt file)
- **`training_time_seconds`**: Time to train this specific model
- **`total_training_time_seconds`**: Total time for all 16 combinations
- **`num_models_trained`**: Number of models trained (should be 16)

### How to Read

1. **Find the best model**: Look at `best_model_info` for the top-performing configuration
2. **Compare all combinations**: Browse `all_results` to see how different hyperparameters affect performance
3. **Sort by metric**: You can sort `all_results` by any metric (accuracy, F1, AUC-PR, etc.) to find optimal settings


**Note:** Models are sorted by validation accuracy (descending).

### 2.2 CSV Format: `model_comparison.csv`

**Purpose:** Spreadsheet-friendly format for analysis

**Columns:**
- `Model`: Model name (BERT, ELECTRA, RoBERTa)
- `Validation Accuracy`: Best validation accuracy
- `Validation Precision`: Macro precision
- `Validation Recall`: Macro recall
- `Validation F1`: Macro F1 score
- `Validation AUC-PR`: Macro AUC-PR
- `Total Parameters`: Number of model parameters
- `Model Size (MB)`: Model file size
- `Training Time (seconds/minutes)`: Time to train best model
- `Total Search Time (minutes)`: Time for all 16 combinations
- `Dropout Rate`, `Learning Rate`, `Batch Size`, `Weight Decay`: Best hyperparameters

**How to Use:**
- Open in Excel, Google Sheets, or pandas
- Sort/filter by any column
- Create visualizations

## 3. Best Model Reports (Text Files)

**Files:** `bert_best_model_report.txt`, `electra_best_model_report.txt`, `roberta_best_model_report.txt`

### Contents

Each report contains:

1. **Model Path**: Location of saved model weights
2. **Best Model Info**: JSON dump of best model parameters and metrics
3. **Classification Report**: Per-class metrics including:
   - Precision, Recall, F1-score for each emotion class
   - Support (number of samples per class)
   - Macro and weighted averages

### Example Classification Report

```
              precision    recall  f1-score   support

     sadness       0.95      0.94      0.94       500
          joy       0.96      0.97      0.96       600
         love       0.92      0.91      0.91       450
        anger       0.93      0.94      0.93       550
         fear       0.91      0.90      0.90       400
      suprise       0.94      0.95      0.94       500

    accuracy                           0.94      3000
   macro avg       0.94      0.94      0.94      3000
weighted avg       0.94      0.94      0.94      3000
```

### How to Interpret

- **Per-class metrics**: Show how well the model performs for each emotion
- **Macro avg**: Average across all classes (treats all classes equally)
- **Weighted avg**: Average weighted by class support (accounts for class imbalance)
- **Support**: Number of validation samples per class

## 4. Training Plots (PNG Files)

### 4.1 Training History Plots

**Naming:** `{MODEL}_{param_string}.png` (e.g., `BERT_batch_size16_dropout_rate0p1_lr2e-05_weight_decay0p0.png`)

**Contents:** 6 subplots showing:
1. **Loss**: Training vs validation loss over epochs
2. **Accuracy**: Training vs validation accuracy
3. **Precision (Macro)**: Training vs validation precision
4. **Recall (Macro)**: Training vs validation recall
5. **F1 Score (Macro)**: Training vs validation F1
6. **AUC-PR (Macro)**: Training vs validation AUC-PR

**How to Read:**
- Blue solid line: Training metrics
- Red dashed line: Validation metrics
- Look for:
  - **Overfitting**: Large gap between training and validation metrics
  - **Convergence**: Metrics plateauing over epochs
  - **Best epoch**: Point where validation loss is minimum (early stopping)

### 4.2 Confusion Matrices

**Naming:** 
- `{model}_confusion_matrix_counts_{model_type}.png` (raw counts)
- `{model}_confusion_matrix_normalized_{model_type}.png` (percentages)

**Contents:** 
- Rows: True labels
- Columns: Predicted labels
- Color intensity: Number/percentage of predictions

**How to Read:**
- **Diagonal**: Correct predictions (darker = better)
- **Off-diagonal**: Misclassifications
- **Normalized version**: Shows percentages (easier to compare classes of different sizes)

## 6. Understanding Metrics

### Accuracy
- **Definition**: Percentage of correct predictions
- **Range**: 0.0 to 1.0 (higher is better)
- **Use case**: Overall performance indicator

### Precision (Macro)
- **Definition**: Average precision across all classes
- **Formula**: (TP) / (TP + FP) for each class, then averaged
- **Interpretation**: When model predicts a class, how often is it correct?
- **Use case**: Important when false positives are costly

### Recall (Macro)
- **Definition**: Average recall across all classes
- **Formula**: (TP) / (TP + FN) for each class, then averaged
- **Interpretation**: Of all actual instances of a class, how many did we find?
- **Use case**: Important when false negatives are costly

### F1 Score (Macro)
- **Definition**: Harmonic mean of precision and recall
- **Formula**: 2 × (Precision × Recall) / (Precision + Recall)
- **Interpretation**: Balanced metric combining precision and recall
- **Use case**: Good overall metric when classes are imbalanced

### AUC-PR (Area Under Precision-Recall Curve)
- **Definition**: Area under the precision-recall curve
- **Range**: 0.0 to 1.0 (higher is better)
- **Interpretation**: 
  - 1.0: Perfect classifier
  - 0.5: Random classifier
  - < 0.5: Worse than random
- **Use case**: Better than AUC-ROC for imbalanced datasets
- **Note**: This pipeline uses AUC-PR instead of AUC-ROC

## 8. Quick Start: Finding the Best Model

3. **Note the `model_path`** to load the saved weights

5. **Review the corresponding report file** (e.g., `roberta_best_model_report.txt`) for detailed metrics
6. **Look at training plots** to understand training dynamics

---

## 9. Tips for Analysis

### Comparing Models
- Use `model_comparison.csv` for easy sorting/filtering
- Compare multiple metrics, not just accuracy
- Consider training time vs. performance trade-off

### Understanding Hyperparameter Effects
- In `hp_results_*.json`, compare `all_results` entries
- Look for patterns (e.g., does higher dropout always help?)
- Check if certain parameter combinations consistently perform well

### Detecting Issues
- **Overfitting**: Large gap between training and validation metrics in plots
- **Underfitting**: Both training and validation metrics are low
- **Class imbalance**: Check confusion matrices and per-class metrics in reports
- **Convergence**: Training plots should show metrics stabilizing

## 10. Example: Reading Results in Python

```python
import json
import pandas as pd

# Load comparison results
with open('results/model_comparison.json', 'r') as f:
    comparison = json.load(f)

# Find best model
best_model = comparison[0]  # Already sorted by accuracy
print(f"Best model: {best_model['model']}")
print(f"Accuracy: {best_model['val_accuracy']:.4f}")
print(f"F1 Score: {best_model['val_f1']:.4f}")

# Load hyperparameter search results
with open('results/hp_results_bert.json', 'r') as f:
    bert_results = json.load(f)

# Find all models with accuracy > 0.93
high_performers = [
    r for r in bert_results['all_results'] 
    if r['val_accuracy'] > 0.93
]

# Load CSV for analysis
df = pd.read_csv('results/model_comparison.csv')
print(df.sort_values('Validation F1', ascending=False))
```
